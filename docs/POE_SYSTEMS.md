# Power fantasy systems

Equipment is **attribute stones** (not traditional gear). See **[STONES_AND_COMBAT.md](./STONES_AND_COMBAT.md)** for the full design.

Quick summary:

- **8 sockets** = 8 attributes (colored stones)
- **5 rarities** → 1–5 effects (common → legendary)
- **Procs**: bolts, novas, burn/chill/shock, blur DR, onslaught
- **Skill ranks** on `/skills` (gold)
- **Drops** from dungeon kills → equip on `/equipment`

Asset readiness (D1/CDN monsters): **[ASSET_READINESS.md](./ASSET_READINESS.md)**.
